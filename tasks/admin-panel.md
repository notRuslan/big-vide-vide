Нужно реализовать админ-панель.

1. Самый первый пользователь системы после регистрации получает статус администратора.
2. Если есть статус администратора, то ему доступна страница /admin, где обрабатывается список пользователей.
3. Можно зайти в карточку пользователя (только администратору) и изменить информацию о юзере: имя пользователя или пароль, или добавить ему статус администратора.
4. В интерфейсе сверху у администратора есть кнопка «Перейти в админ-панель».
