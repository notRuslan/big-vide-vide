Нужно сделать функционал смены пароля.

1. В интерфейсе появляется блок «Личный кабинет». Ссылка на него сверху главного экрана.
2. В личном кабинете можно увидеть текущих юзеров и цифру с количеством задач.
3. Есть кнопка «Сменить пароль», по нажатию на которую происходит переход на страницу, где надо ввести старый пароль и два раза новый.
4. После этого новый пароль сохраняется.
